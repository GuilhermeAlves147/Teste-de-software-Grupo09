# Teste-de-Software-grupo09
# Projeto Final 

## Visão geral
Testes e relatórios sobre um sistema de marketplace que simula uma plataforma de comércio eletrônico, na qual usuários podem atuar como vendedores — cadastrando e gerenciando produtos organizados por categorias — ou como clientes, montando carrinhos de compra e finalizando pedidos. O projeto visa botar em prática as técnicas dos testes de software estudados em sala e fora dela para melhor compreensão dos efeitos positivos que um bom planejamento de testes pode ter.

## Tema

Marketplace (vendedores, clientes, produtos, categorias, fornecedores, carrinho e pedidos).
